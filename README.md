## 📁 **WiFiPIDTuner.cpp / .h**
**Модуль удалённой настройки PID-регулятора через Wi-Fi**

Создаёт точку доступа `PID_Tuner`, к которой можно подключиться со смартфона или компьютера. Через веб-интерфейс можно в реальном времени изменять коэффициенты `Kp`, `Ki`, `Kd` и сразу видеть их влияние на движение робота.

**Основные возможности:**
- Точка доступа Wi-Fi (пароль по умолчанию: `12345678`)
- Веб-страница с ползунками и пресетами (медленно/средне/быстро)
- Отправка новых коэффициентов на ESP32 через HTTP-запросы
- Автообновление текущих значений каждые 2 секунды
- Коэффициенты хранятся статически и доступны из основного кода через `getPID()`

## 📁 **Yahboom_8CH_Line.cpp / .hpp**
**Драйвер для 8-канального инфракрасного датчика линии Yahboom**

Обрабатывает данные с линейного датчика, подключённого к ESP32 через UART (Serial2, пины RX=16, TX=17). Модуль присылает данные в двух режимах: цифровом (0/1 — есть/нет линии) и аналоговом (значения от 0 до 4095).

**Основные функции:**
- `serial_init()` — инициализация Serial2 для связи с датчиком
- `recv_data()` — чтение входящих данных и их парсинг
- `SET_Eight_Mode()` — настройка режима работы датчика (цифровой/аналоговый)
- `Deal_Usart_Data()` — обработка **цифровых** данных (в массив `IR_Data_number[8]`)
- `Deal_Usart_AData()` — обработка **аналоговых** данных (в массив `IR_Data_Anglo[8]`)
- `IR_Data_number` — глобальный массив с состояниями 8 датчиков (0 — белое / 1 — чёрная линия)

## 🔗 **Как они связаны**

Типичное использование в `main()`:

```cpp
#include "WiFiPIDTuner.h"
#include "Yahboom_8CH_Line.hpp"

WiFiPIDTuner pidTuner("мойпароль");

void setup() {
    serial_init();           // запускаем датчик линии
    pidTuner.begin();        // запускаем Wi-Fi настройку
    pidTuner.printInfo();    // выводим IP и SSID в Serial
}

void loop() {
    pidTuner.handleClient(); // обрабатываем входящие запросы из браузера
    
    recv_data();             // читаем данные с датчика
    if (g_new_package_flag) {
        Deal_Usart_Data();   // парсим цифровые данные
        g_new_package_flag = 0;
    }
    
    float Kp, Ki, Kd;
    pidTuner.getPID(Kp, Ki, Kd);  // получаем актуальные коэффициенты
    
    // Здесь ваш PID-регулятор на основе IR_Data_number[8]
}
```

## 🎯 **Назначение проекта**

Робот для **соревнований по следованию по линии**. Wi-Fi интерфейс позволяет быстро подбирать PID-коэффициенты без перепрошивки — просто открываете браузер на телефоне, двигаете ползунки и наблюдаете за поведением робота на трассе.
